Модальное окно sf-modal

Все возможности на опубликованном Framework этой админки. Каждая кнопка открывает своё окно; справа внизу — журнал событий modal:*.

1. Содержимое

Заголовок и текст атрибутами; слоты header, content, footer; содержимое без слота попадает в основную часть.

Свой заголовок из слота header

Основная часть из слота content.

Этот абзац написан внутри <sf-modal> без атрибута slot — и всё равно показан.

2. Положение и размер

position: по центру, сбоку (inline-start/inline-end — модальная боковая панель), сверху, снизу; fullscreen; width и height.

Положение по умолчанию.

Модальная боковая панель; в RTL встаёт справа.

Модальная боковая панель с другой стороны.

Панель у верхнего края.

Панель у нижнего края.

Окно занимает весь экран.

Ширина 40rem, высота 20rem.

3. Подложка и закрытие

overlay-preset="focus" добавляет размытие; overlay="false" — без подложки; close-on-overlay="false" и close-on-esc="false"; unclose — закрыть можно только кнопкой внутри.

Тёмная подложка с размытием фона.

Подложка с backdrop-blur-large.

Страница за окном не затемнена.

Закрывается крестиком, не кликом мимо и не Esc.

Крестика нет, Esc и клик мимо не работают.

4. Шапка и сворачивание

show-header="false", show-close="false"; hide добавляет кнопку «Свернуть»: окно остаётся открытым, но убирается, а вернуть его можно снаружи — методом show().

Окно без шапки. Закрыть — кнопкой ниже, Esc или кликом мимо.

Esc и клик мимо по-прежнему закрывают.

Нажмите «Свернуть» в шапке, затем «Развернуть свёрнутое» на странице.

5. Загрузка содержимого

mode="ajax" с адресом или с селектором блока на странице; mode="iframe"; preload="false" — загрузка при первом открытии; методы setSrc() и reloadContent().

Этот текст скопирован из скрытого блока #demo-hidden на странице.

А этот — из #demo-hidden-2, после setSrc().

6. Встроенный режим

display="inline" — окно стоит в потоке страницы, без подложки и без стопки. Его показывает атрибут open.

Это то же окно, только внутри страницы.

7. Внутри блока

Внутри элемента с data-sf-overlay-container окно закрывает только этот блок, страница прокручивается. Слева — <sf-modal>; справа — окно из скрипта с param.container.

Подложка и окно — внутри рамки.

8. Стопка окон и события

Окно открывает второе поверх себя; Esc закрывает верхнее, фокус возвращается. Второе окно отменяет своё закрытие один раз — preventDefault() на modal:before-close.
