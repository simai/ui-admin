# sf-admin-shell

Каркас страницы админки (решения C420, C415–C419): полоса сообщений сверху,
меню слева, голова страницы и содержимое. Страница прокручивается целиком
(прокрутка документа): полоса, меню, верхняя строка телефона и голова данных
прилипают. Каркас расставляет то, что ему дали, и не рисует ни меню, ни
голову сам.

```html
<sf-admin-shell product="Larena Panel">
  <sf-alert-bar slot="bar" …></sf-alert-bar>
  <sf-admin-menu slot="menu" …></sf-admin-menu>
  <sf-header-page slot="head" heading="DNS-зоны"></sf-header-page>
  <sf-admin-activity slot="top-end" size="1"></sf-admin-activity>
  <p>Содержимое — дети без slot.</p>
</sf-admin-shell>
```

## Места

- `bar` — полоса сообщений (sf-alert-bar); у каркаса появляется `data-bar`.
- `menu` — sf-admin-menu. Пока меню не нарисовано, его место держится
  (`menu-reserve`: `rail-column` — рейка и колонка, `rail` — только рейка,
  `none`): страница не сдвигается, когда меню приходит. Если человек скрыл
  колонку (настройка меню `second: false`), держится только рейка.
- `head` — голова страницы (sf-header-page); `main` получает её заголовок
  именем.
- `top-end` — конец верхней строки телефона: индикатор действий и колокол.
- дети без `slot` — содержимое.

Первой в странице стоит ссылка «Перейти к содержимому»: она видна по фокусу и
ведёт в `main`.

## Ширина

`width="list"` (по умолчанию) — содержимое во всю ширину. `width="read"` —
чтение: не шире `--sf-container-1--size-max` (960), у левого края.

## Телефон (уже 44rem)

Сверху тонкая липкая строка: кнопка меню, название продукта (`product`),
место `top-end`. Кнопка открывает меню на весь экран (`menu-open`), Escape и
переход по пункту закрывают его, фокус возвращается на кнопку. Ширина 44rem —
та же, что у sf-admin-menu (в образце было 48rem).

## Для соседей

Каркас пишет `--sf-admin-shell-stick` — высоту того, что прилипло сверху
(полоса и, на телефоне, верхняя строка). Липкие части страницы (голова данных,
панель таблицы) ставят `top: var(--sf-admin-shell-stick, 0)`. Тот же отступ
каркас ставит документу в `scroll-padding-block-start`, чтобы переход по якорю
не прятал заголовок под полосой.

## Действия и события

- `open-menu`, `close-menu`, `focus-content`.
- `sf-admin-shell-menu-open`, `sf-admin-shell-menu-close` с `{reason}`.

## Временные замены

- До AS-2 (место конца строки крошек в sf-header-page): каркас раскладывает
  `.sf-admin-shell-path` строкой — крошки слева, индикатор справа
  (CSS помечен «Fallback until AS-2»).
- AS-1 и AS-3 каркас не заменяет: полоса информации в тёмной теме и перенос
  длинного заголовка придут с парой SIMAI Framework.
