# admin-activity

x

## Параметры

Справочник собран из манифеста компонента в сборке-кандидате набора (`simai/ui-admin@81eb44e4662d`) и обновляется вместе с ней. Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `history-href` — `historyHref`.

| | |
|:---|:---|
| Тег | `<sf-admin-activity>` |
| Назначение | Фоновые действия админки: «Идёт N», пока что-то идёт; красная метка рядом, пока человек не открыл список после неудачи; «Не удалось N» словами, когда ничего не идёт; элемента нет, когда показать нечего. Список действий открывается в `sf-popover`; о конце действия говорят `SF.notify` и, при неудаче, уведомление. |
| Контракт | `smart.admin-activity`, версия `1.0.0` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто. Классы, которые получает корневой элемент компонента.
- `root-style` — `string`, по умолчанию пусто. Встроенные стили корневого элемента компонента, включая пользовательские свойства.
- `history-href` — `string`, по умолчанию пусто. Адрес истории действий: «Все действия» внизу списка; туда же ведёт уведомление о неудаче, если у действия нет своего адреса.
- `size` — `string`, по умолчанию `1/2`, значения: `1/2`, `1`. Ступень кнопки: 1/2 в строке крошек, 1 в верхней строке телефона рядом с колоколом.
- `placement` — `string`, по умолчанию `bottom-end`, значения: `bottom-end`, `bottom-start`, `bottom`. Откуда открывается список относительно кнопки.
- `notify` — `boolean`, по умолчанию `true`. Конец действия сообщается сам: `SF.notify` success (исчезает сам) или error (остаётся до закрытия) и уведомление в списке админки. Выключено — только событие `finished`.
- `aria-label` — `string`, по умолчанию пусто.
- `runs` — `array`, по умолчанию `[]`. Действия хоста, задаются заново при каждом изменении: каждое `{id, label, state (running|failed|done|cancelled), value, total, unit, text, href, object, cancelable}`. Действие, которое вышло из `running`, впервые пришло уже законченным или неудавшимся или пропало во время работы, закончилось: элемент сообщает об этом один раз. Первый список ни о чём не сообщает.

## События

События приходят на сам элемент и всплывают.

- `sf-admin-activity-open` — `detail` не описан. Список открыт: неудачи в нём считаются увиденными, метка уходит.
- `sf-admin-activity-close` — `detail` не описан. Список закрыт.
- `sf-admin-activity-retry` — `detail`: `{ id: string }`. «Повторить» у неудавшегося действия; через порт элемент спрашивает `activity.retry {id}` и читает заново.
- `sf-admin-activity-cancel` — `detail`: `{ id: string }`. «Отменить» у идущего действия; через порт элемент спрашивает `activity.cancel {id}` и читает заново.
- `sf-admin-activity-finished` — `detail`: `{ id: string, state: string }`. Действие закончилось (`done` или `failed`), один раз на страницу. Об отменённом элемент ничего не сообщает (ни сообщения, ни уведомления).

## Методы

- `refresh()` — возвращает `object`. Заново читает действия (`activity.load`), если порт предлагает `activity`.
- `show()` — возвращает `object`. Открывает список; отказ, если показать нечего.
- `close()` — возвращает `object`. Закрывает список.

## CSS-переменные

Задаются на элементе или на любом предке.

| Переменная | Тип | Что задаёт |
|:---|:---|:---|
| `--sf-admin-activity-gap` | `length` | Промежуток в кнопке. |
| `--sf-admin-activity-list-width` | `length` | Ширина списка. |
| `--sf-admin-activity-list-max-height` | `length` | Наибольшая высота списка. |
| `--sf-admin-activity-failed-color` | `color` | Цвет метки неудачи. |
| `--sf-admin-activity-trigger-padding-inline` | `length` | Отступ кнопки по бокам. |

## Доступность

- Роль: `group`.
- Доступное имя: даёт сам компонент.
- Клавиши: `Tab`, `Enter`, `Space`, `Escape`.
- Фокус: Кнопка по порядку чтения; список — у `sf-popover`, фокус возвращается на кнопку при закрытии.
