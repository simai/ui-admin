# Каркас админки

<!-- release:badges -->
:badge[sf-admin-shell]{variant=main scheme=on-surface size=1} :badge[Версия 1.0.1]{variant=tonal scheme=neutral size=1} :badge[предварительный]{variant=tonal scheme=warning size=1}
<!-- /release:badges -->

Каркас расставляет части экрана админки: полосу сообщений над всем, меню администратора, голову страницы и содержимое. Прокручивается документ; полоса, меню и на телефоне тонкая верхняя строка остаются на месте. Данных каркас не спрашивает.

## Пример

Каркас со всеми местами: полоса сообщений, меню, голова со строкой пути и содержимое. Сузьте окно до телефона — меню спрячется за кнопку в верхней строке; журнал под примером покажет открытие и закрытие меню.

:::

## Места

| Место | Что в нём |
|:---|:---|
| `bar` | Полоса сообщений `sf-alert-bar` над всем экраном. |
| `menu` | Меню администратора `sf-admin-menu`. |
| `head` | Голова страницы `sf-header-page`; строку пути ставят в её место `path` с классом `sf-admin-shell-path`. |
| `top-end` | Конец верхней строки телефона: второй индикатор фоновых действий. |
| без `slot` | Содержимое страницы, ориентир `main`. |

Высоту того, что прилипло сверху, каркас пишет в `--sf-admin-shell-stick`: по ней страница прилепляет свои части сразу под каркасом.

## Ширина чтения

`width="read"` ставит содержимое на ширину чтения у начала рабочей области — для форм настроек и текста. По умолчанию (`list`) содержимое занимает всю рабочую область.

:::example {id="components/admin-shell-read" label="Форма на ширине чтения"}
:::

## Без меню

`menu-reserve="none"` не держит места под меню — для мастера установки или страницы ошибки. `rail` держит место одной рейки, `rail-column` — рейки и колонки раздела.

:::

## Параметры

Справочник собран из манифеста компонента в выпуске набора `admin-45b580402884` (версия 1.2.2) и обновляется вместе с выпуском. Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `history-href` — `historyHref`.

| | |
|:---|:---|
| Тег | `<sf-admin-shell>` |
| Назначение | Каркас экрана админки: полоса сообщений над всем, колонка меню администратора, голова страницы и содержимое. Прокручивается документ; полоса, меню и на телефоне тонкая верхняя строка остаются на месте. Первой стоит ссылка к содержимому, место меню держится до его отрисовки, ширина — списка или чтения. |
| Контракт | `smart.admin-shell`, версия `1.0.1` |

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто. Классы, которые получает корневой элемент компонента.
- `root-style` — `string`, по умолчанию пусто. Встроенные стили корневого элемента компонента, включая пользовательские свойства.
- `width` — `string`, по умолчанию `list`, значения: `list`, `read`. Ширина содержимого: `list` — вся рабочая область; `read` — ширина чтения (`--sf-container-1--size-max`, 960) у начала строки, для форм и текста.
- `menu-reserve` — `string`, по умолчанию `rail-column`, значения: `rail`, `rail-column`, `none`. Место, которое держится для меню, пока оно не нарисовано, чтобы рабочая область не сдвинулась, когда оно придёт: `rail` — рейка (56); `rail-column` — рейка и колонка раздела (56 + 256), только рейка, если меню сказало `expected-columns="1"` (у строки страницы нет открытого раздела) или человек скрыл колонку; `none` — ничего. Есть ли у раздела страницы колонка, знает сервер.
- `product` — `string`, по умолчанию пусто. Название продукта в верхней строке телефона («Larena Panel»).
- `skip-label` — `string`. Текст ссылки к содержимому; пусто — «Перейти к содержимому» на языке страницы.
- `menu-open` — `boolean`, по умолчанию `false`. Открыто ли меню на телефоне: уже 44rem меню занимает место рабочей области. Пишут кнопка меню, Escape, выбранная в меню страница или сама страница; на широком экране ничего не меняет.

## События

События приходят на сам элемент и всплывают.

- `sf-admin-shell-menu-open` — `detail`: `{ reason }`. Меню на телефоне открыто: кнопкой или действием `open-menu`.
- `sf-admin-shell-menu-close` — `detail`: `{ reason }`. Меню на телефоне закрыто: кнопкой, Escape, выбранной в меню страницей (`sf-admin-menu-navigate`), окном шире телефона, фокусом в рабочей области или действием `close-menu`.

## Методы

- `openMenu()` — возвращает `object`. Открывает меню на телефоне (`menu-open`); фокус переходит на первый элемент меню. Отказ `no-menu`, если в каркасе нет меню.
- `closeMenu()` — возвращает `object`. Закрывает меню на телефоне; фокус возвращается на кнопку меню.
- `focusContent()` — возвращает `object`. Переводит фокус в рабочую область (ориентир `main`) и прокручивает её к началу: так делает ссылка к содержимому, и так продукт может сделать после смены страницы без перезагрузки.

## CSS-переменные

Задаются на элементе или на любом предке.

| Переменная | Тип | Что задаёт |
|:---|:---|:---|
| `--sf-admin-shell-background-color` | `color` | Фон каркаса. |
| `--sf-admin-shell-content-padding-inline` | `length` | Отступы содержимого по бокам. |
| `--sf-admin-shell-content-padding-block` | `length` | Отступы содержимого сверху и снизу. |
| `--sf-admin-shell-read-width` | `length` | Ширина чтения (`width="read"`). |
| `--sf-admin-shell-menu-reserve` | `length` | Место, которое держится для меню до его отрисовки. |
| `--sf-admin-shell-top-padding` | `length` | Отступ верхней строки телефона. |
| `--sf-admin-shell-divider-color` | `color` | Цвет разделительных линий каркаса. |
| `--sf-admin-shell-z-index` | `number` | Слой липких частей каркаса (`z-index`). |
| `--sf-admin-shell-stick` | `length` | Пишет сам каркас: высота того, что прилипло сверху (полоса и на телефоне верхняя строка). Липкая голова данных ставит `inset-block-start: var(--sf-admin-shell-stick)`. |

## Доступность

- Роль: `none`.
- Доступное имя: даёт сам компонент.
- Клавиши: `Tab`, `Enter`, `Space`, `Escape`.
- Фокус: Первой стоит ссылка к содержимому; она переводит фокус в рабочую область (`main`, `tabindex="-1"`, имя — из заголовка `h1`). Кнопка меню на телефоне несёт `aria-expanded` и `aria-controls`; при открытии фокус переходит в меню, при закрытии — обратно на кнопку.
