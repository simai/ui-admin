# Оформление

Компоненты набора берут цвета, отступы и высоты из систем SIMAI Framework:
тема, плотность и размеры меняются на всей странице сразу. Для своих
решений у каждого компонента есть несколько публичных CSS-переменных.

## Темы

Светлая и тёмная тема приходят из SIMAI Framework. Тему из профиля меню
выбирает человек, порт сохраняет её намерением `preference.theme`, а страница
применяет её так же, как любая страница SIMAI Framework.

## CSS-переменные

Переменные задают на элементе или на его предке. Пример ниже меняет
заливку рейки и колонки меню:

```css
.page-quiet {
  --sf-admin-menu-first-background-color: var(--sf-surface-3);
  --sf-admin-menu-second-background-color: var(--sf-surface-1);
}
```

:::example {id="guide/appearance" label="Своя заливка меню"}
:::

Значения берите из ролей SIMAI Framework (`--sf-surface-*`,
`--sf-on-surface*`, `--sf-outline*`), а не из своих цветов: так переменная
останется верной и в тёмной теме.

| Компонент | Переменные |
|:---|:---|
| [Каркас](/ru/components/admin-shell/#css-переменные) | фон, отступы содержимого, ширина чтения, место меню, линия, слой, высота прилипшего |
| [Меню](/ru/components/admin-menu/#css-переменные) | цвет, заливка рейки и колонки, линия, отступ, ширины меню для страницы |
| [Уведомления](/ru/components/admin-notifications/#css-переменные) | цвет непрочитанного и решённого, линия, отступы строк и групп |
| [Фоновые действия](/ru/components/admin-activity/#css-переменные) | промежуток, ширина и высота списка, цвет неудачи, отступ кнопки |

## Размеры

Индикатор фоновых действий стоит на лестнице размеров SIMAI Framework:
`size="1/2"` — в строке пути головы страницы, `size="1"` — в верхней строке
телефона рядом с колоколом.
