# Фоновые действия

Долгие действия — выгрузка, резервная копия, перенос сайта — идут в фоне,
пока человек работает дальше. Индикатор фоновых действий говорит, что
сейчас идёт и что не удалось, и не мешает, когда ничего не происходит.

## Что видит человек

- Пока что-то идёт — «Идёт N».
- Рядом — красная отметка неудачи, пока человек не открыл список.
- Когда ничего не идёт, а неудачи есть — «Не удалось N» словами.
- Нечего показать — индикатора нет совсем.

По нажатию открывается список действий: у каждого ход, «Отменить» для
идущего и «Повторить» для неудачного, внизу — «Все действия».

## Откуда берутся действия

Список действий даёт страница в атрибуте `runs` и задаёт его заново при
каждом изменении. Первый список индикатор принимает молча: о действиях,
которые уже кончились до загрузки страницы, он не сообщает. Поэтому первый
список удобно напечатать прямо в разметке.

```html
<sf-admin-activity history-href="/admin/activity"
  runs='[{"id":"b1","label":"Резервная копия","state":"running","value":40,"total":100,"unit":"%"}]'>
</sf-admin-activity>
```

## Конец действия

Когда действие кончается, индикатор говорит об этом один раз:

:::diagram {engine=mermaid title="Что происходит, когда действие кончилось"}
flowchart LR
  run["Действие"] --> state{"Итог"}
  state -- "done" --> ok["Сообщение «готово», исчезает само"]
  state -- "failed" --> err["Сообщение об ошибке, ждёт закрытия"]
  err --> notice["Уведомление в списке"]
  state -- "cancelled" --> quiet["Ничего"]
:::

`notify="false"` выключает сообщения: остаётся только событие `finished`.

## Два индикатора

На широком экране индикатор стоит в строке пути головы страницы
(`size="1/2"`). На телефоне голова уходит со строки, и второй индикатор
ставят в место `top-end` каркаса рядом с колоколом (`size="1"`).
