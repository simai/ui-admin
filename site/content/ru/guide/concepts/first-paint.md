# Первый кадр

Страница админки не должна прыгать при загрузке: меню появляется на том
месте, которое для него держали, а содержимое не съезжает вбок. Для этого
есть два средства — место меню и первый ответ в странице.

## Место меню

Пока код меню не пришёл, каркас держит под него место: `menu-reserve`
задаёт его ширину. `rail-column` — рейка и колонка раздела, `rail` — одна
рейка, `none` — ничего. Сервер знает, есть ли у раздела страницы колонка,
и печатает нужное значение.

Само меню до ответа рисует заготовку той же ширины: `expected-columns="1"`
для страницы без открытого раздела (главная панель), `2` — с открытым.

:::diagram {engine=mermaid title="Первые кадры страницы"}
sequenceDiagram
  participant Браузер
  participant Каркас
  participant Меню
  participant Порт
  Браузер->>Каркас: разметка и стили
  Каркас-->>Браузер: место меню нужной ширины
  Браузер->>Меню: код меню
  Меню-->>Браузер: заготовка или первый ответ
  Меню->>Порт: navigation.load
  Порт-->>Меню: ответ, меню на том же месте
:::

## Первый ответ в странице

Сервер может напечатать первый ответ `navigation.load` вместе со страницей —
островом `data-sf-settings` внутри меню. Тогда меню рисует разделы сразу,
без заготовки, а порт отвечает уже позади.

```html
<sf-admin-menu aria-label="Меню" current="srv.dns">
  <script type="application/json" data-sf-settings>
    {"first-answer": {"answer": "applied", "items": [ … ]}}
  </script>
</sf-admin-menu>
```

## Ширина меню для страницы

Меню публикует свою ширину на `:root` в четырёх переменных:
`--sf-admin-menu-one-column-inline-size`,
`--sf-admin-menu-two-columns-inline-size` и их компактные пары. Страница
может держать место под меню по ним, если ставит его вне каркаса.
