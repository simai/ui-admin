# Введение

SIMAI Admin — набор компонентов SIMAI Framework для каркаса админки: меню
разделов, рамка страницы, уведомления и индикатор фоновых действий. Набор
отвечает за то, что окружает данные страницы. Сами списки и записи рисует
набор SIMAI View, служебные экраны собираются по
рецептам SIMAI Framework.

## С чего начать

- [Быстрый старт](quick-start/) — каркас с меню за пять минут.
- [Подключение](connection/) — одна строка, npm, своя копия, версии и лицензия.

- [Полный пример админки](demo/) — демонстрационная админка на всю страницу.

## Из чего состоит

| Компонент | Элемент | Что делает |
|:---|:---|:---|
| [Каркас админки](/ru/components/admin-shell/) | `sf-admin-shell` | Расставляет полосу сообщений, меню, голову страницы и содержимое; держит место меню и прилипает при прокрутке. |
| [Меню администратора](/ru/components/admin-menu/) | `sf-admin-menu` | Рисует разделы, поиск, избранное, профиль и колокол по ответам сервера. |
| [Уведомления](/ru/components/admin-notifications/) | `sf-admin-notifications` | Показывает уведомления по дням: в панели и на странице истории. |
| [Фоновые действия](/ru/components/admin-activity/) | `sf-admin-activity` | Говорит, что идёт в фоне и что не удалось. |

:::diagram {engine=mermaid title="Как части набора связаны со страницей и сервером"}
flowchart LR
  server["Сервер приложения"] -- "ответы порта навигации" --> menu["Меню администратора"]
  server -- "уведомления через тот же порт" --> notices["Уведомления"]
  page["Код страницы"] -- "список действий runs" --> activity["Фоновые действия"]
  shell["Каркас админки"] --- menu
  shell --- activity
  menu -- "колокол открывает" --> notices
  activity -- "неудача становится уведомлением" --> notices
:::

Каркас ничего не спрашивает у сервера: он только расставляет части. Меню и
уведомления читают один порт навигации — объект страницы, который отвечает
на их запросы. Индикатор действий получает список от страницы.
