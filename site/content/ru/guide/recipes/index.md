# Рецепты

Рецепт — готовое решение задачи админки из частей набора и SIMAI Framework:
что поставить на страницу, в каком порядке и что получится.

## Рецепты набора

| Рецепт | Что получится |
|:---|:---|
| [Страница настроек](settings-page/) | Форма настроек в каркасе на ширине чтения, с меню и головой страницы. |
| [Колокол с панелью уведомлений](notifications-bell/) | Колокол меню открывает панель уведомлений справа. |
| [Долгая операция](long-operation/) | Действие идёт в фоне, конец сообщается сам, неудача попадает в уведомления. |

## Рецепты SIMAI Framework

Служебные экраны админки — формы настроек, сохранение и ошибки, системные
сообщения — собираются из компонентов SIMAI Framework. Их рецепты живут в
документации SIMAI Framework:

| Рецепт | О чём |
|:---|:---|
| [Рамка админки](https://ui.simai.io/ru/recipes/navigate/admin-frame/) | Из чего состоит экран админки. |
| [Форма настроек](https://ui.simai.io/ru/recipes/edit/settings-form/) | Разделы, поля и подсказки страницы настроек. |
| [Сохранение и ошибки](https://ui.simai.io/ru/recipes/edit/save-and-errors/) | Кнопка сохранения, ошибки полей и ответа сервера. |
| [Уведомления](https://ui.simai.io/ru/recipes/notify/notifications/) | Всплывающие сообщения и их сроки. |
| [Системная полоса](https://ui.simai.io/ru/recipes/notify/system-bar/) | Полоса сообщений над всем экраном. |
| [Долгая работа](https://ui.simai.io/ru/recipes/progress/long-job/) | Ход долгой операции на странице. |
| [Панель показателей](https://ui.simai.io/ru/recipes/notify/dashboard/) | Главная панель из плиток. |

Списки и карточки записей собирает набор SIMAI View.
